# R-NB-005 — No absolute/local paths in notebook cells

**Category:** Notebooks  
**Severity:** low  
**Weight:** 2

## Why it matters

Machine-specific absolute paths commonly fail when a notebook moves to a
different account, filesystem layout, or operating system. A matching path on
another host can still work, so this is a portability risk rather than proof of
failure.

## Suppressing

Inline, on the reported line: `# adduce: ignore=R-NB-005`  
Project-wide, in `adduce.toml` or `[tool.adduce]`: `ignore = ["R-NB-005"]`

Suppressed findings still appear in reports, marked as ignored.
