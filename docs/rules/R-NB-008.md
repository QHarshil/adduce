# R-NB-008 — Result-bearing notebooks have a script equivalent

**Category:** Notebooks  
**Severity:** low  
**Weight:** 2

## Why it matters

A script, Jupytext source, or Papermill entry point can make a result-bearing
notebook easier to run headlessly, review as text, and integrate into
automation. Some notebooks already support those workflows directly, so the
finding asks for an explicit executable path rather than assuming they cannot.

## Suppressing

Inline, on the reported line: `# adduce: ignore=R-NB-008`  
Project-wide, in `adduce.toml` or `[tool.adduce]`: `ignore = ["R-NB-008"]`

Suppressed findings still appear in reports, marked as ignored.
