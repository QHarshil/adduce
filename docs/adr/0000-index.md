# Architecture decision records

Each record states one decision, the context that forced it, and the
consequences we accepted. A record is not edited to match later reality: if a
decision changes, a new record supersedes it and says so.

`Accepted` means the decision is settled, not that the code implements it. Where
a record describes behaviour that does not exist yet, it says so.
